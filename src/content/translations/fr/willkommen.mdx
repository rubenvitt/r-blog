Ce blog est ma nouvelle maison sur le web. Construit avec Astro, stylé avec Tailwind CSS et hébergé sur Cloudflare Pages. Tout est open source, tout est sous mon contrôle.

## Pourquoi changer ?

Ghost, c'était bien — l'éditeur est fantastique, et les slash commands sont un vrai plaisir. Mais je voulais un **contrôle total** sur mon design et mes composants. Et je voulais mes articles en Markdown, dans un dépôt Git.

<Callout type="tip">
  Ce blog utilise MDX — autrement dit, je peux utiliser des composants Astro directement dans mes articles en Markdown.
</Callout>

### Coloration syntaxique

```typescript
interface BlogPost {
  title: string;
  date: Date;
  tags: string[];
  draft: boolean;
}

function getPublishedPosts(posts: BlogPost[]): BlogPost[] {
  return posts
    .filter((post) => !post.draft)
    .sort((a, b) => b.date.valueOf() - a.date.valueOf());
}
```

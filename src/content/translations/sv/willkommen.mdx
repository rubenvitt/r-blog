Den här bloggen är mitt nya hem på webben. Byggd med Astro, stylad med Tailwind CSS och hostad på Cloudflare Pages. Allt open source, allt under min kontroll.

## Varför bytet?

Ghost var bra — editorn är fantastisk, och slash-kommandona är roliga att använda. Men jag ville ha **full kontroll** över min design och mina komponenter. Och jag ville ha mina inlägg som Markdown i Git-repot.

<Callout type="tip">
  Den här bloggen använder MDX — det betyder att jag kan använda Astro-komponenter direkt i mina Markdown-inlägg.
</Callout>

  title: string;
  date: Date;
  tags: string[];
  draft: boolean;
}

function getPublishedPosts(posts: BlogPost[]): BlogPost[] {
  return posts
    .filter((post) => !post.draft)
    .sort((a, b) => b.date.valueOf() - a.date.valueOf());
}

This blog is my new home on the web. Built with Astro, styled with Tailwind CSS, and hosted on Cloudflare Pages. All open source, all under my control.

## Why the switch?

Ghost was good — the editor is fantastic, and slash commands are fun. But I wanted **full control** over my design and my components. And I wanted my posts as Markdown in a Git repo.

<Callout type="tip">
  This blog uses MDX — which means I can use Astro components right inside my Markdown posts.
</Callout>

  draft: boolean;
}

function getPublishedPosts(posts: BlogPost[]): BlogPost[] {
  return posts
    .filter((post) => !post.draft)
    .sort((a, b) => b.date.valueOf() - a.date.valueOf());
}

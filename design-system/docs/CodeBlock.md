# CodeBlock

Codeblock, in beiden Themes dunkel (`code-bg`), damit Code als eigenes Material liest. Kopfzeile mit Dateiname links und Sprache rechts. Hervorhebung über Spans mit den Klassen `k` (Schlüsselwort), `s` (String), `c` (Kommentar). Inline-Code im Fließtext nutzt die Klasse `rv-inline-code`.

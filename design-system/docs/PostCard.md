# PostCard

Ein Eintrag in der Artikelliste, aufgebaut wie eine Zeile im Einsatztagebuch: Datum in einer festen Spalte links, Eintrag rechts, getrennt durch eine Haarlinie oben. Kein Kartenrahmen, kein Bild. Übergib `title`, `date` (ISO), optional `teaser`, `tags`, `readingTime`, `duration` (zeigt den Podcast-Hinweis). Beim Hover schiebt sich eine `signal`-Linie unter den Titel. Unter 560px rutscht das Datum über den Titel.

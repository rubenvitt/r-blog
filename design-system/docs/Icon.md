# Icon

Linien-Icons im 24er-Raster mit 1.8px Strich und runden Enden, Farbe über `currentColor`. Größe per CSS setzen oder die Klasse `rv-icon` (24px) nutzen. Namen: info, tip, warning, danger, spark, arrow, search, moon, audio, heart. Keine Emojis als Gestaltungselement.

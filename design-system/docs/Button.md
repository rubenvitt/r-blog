# Button

Schaltfläche oder Link mit Button-Optik. `secondary` ist der Standard. `primary` (Signalorange mit dunkler Schrift `on-signal`) höchstens einmal pro Ansicht, für die eine Handlung, um die es geht. `ghost` für leise Folgeaktionen wie „Weiterlesen“. Mit `href` wird ein `<a>` gerendert. Beschriftung im Infinitiv oder als Verb zuerst: „Podcast abonnieren“, nicht „Hier klicken“.

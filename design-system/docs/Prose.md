# Prose

Container für Artikeltext. Setzt `body` auf `measure` Breite, h2 mit einem `signal`-Marker im linken Rand, Links unterstrichen in `petrol`, `mark` auf `signal-soft`, Zitate in der Display-Schrift mit Strich in `ink`. Der Marker braucht links 22px Platz; unter 640px entfällt er.

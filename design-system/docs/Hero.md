# Hero

Hero der Startseite: Eyebrow in Mono mit Signal-Quadrat, großer Titel in der Display-Schrift mit einer Signal-Unterlegung (`highlight`), Intro und Buttons. Hinter dem Text liegt ein Punktraster wie auf einer Lagekarte, das nach links ausblendet. Einmal pro Seite. Als `actions` typischerweise ein `Button variant="primary"` und ein `Button`.

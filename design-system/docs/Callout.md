# Callout

Hervorgehobener Hinweis im Artikel. Vier Töne: `info` (petrol), `tip` (moss), `warning` (amber), `danger`. Jeder Ton trägt ein Wort als Label („Hinweis“, „Tipp“, „Achtung“, „Gefahr“) und ein Icon, damit er nicht nur über Farbe unterscheidbar ist. `title` ersetzt das Standardlabel. Höchstens zwei Callouts pro Bildschirmhöhe.
